# Dragon Curve Fractal

A generative visualization of the Dragon Curve fractal built with Python's turtle module, using L-system string rewriting and HSB color cycling for a gradient trail effect.

## Fractal Type
Dragon Curve (Heighway Dragon), generated via L-system rules (F→F, X→X+YF+, Y→-FX-Y).

## Tools & Libraries
- Python 3
- `turtle` (standard library)
- `colorsys` (standard library, for HSB→RGB conversion)

## Setup & Run
1. Clone this repo
2. Run `python dragon_curve.py` (Python 3.x required, no external dependencies)
